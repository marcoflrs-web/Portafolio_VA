📝 Código del Ejemplo

#importar libreria opncv
import cv2
#Guardamos la imagen en una var
imagen =cv2.imread('descarga.jfif')
imgoriginal = imagen.copy() #Creo una copia de la imagen

while True:
    cv2.imshow('imagen', imagen)
    tecla = cv2.waitKey(0)#Espera infinito hasta la presión de una tecla

    if tecla == ord('d'): # D gira a la derecha
        imagen = cv2.rotate(imagen, cv2.ROTATE_90_CLOCKWISE) # Rota a 90 grados en sentido del reloj
        print("Se presiono la tecla",tecla)
    elif tecla == ord('a'): # A gira la izquiera
        imagen = cv2.rotate(imagen, cv2.ROTATE_90_COUNTERCLOCKWISE) # 90 grados al contrario del reloj
        print("Se presiono la tecla",tecla)
    elif tecla == ord('w'): # W gira 180 grados
        print("Se presiono la tecla",tecla) #
        imagen = cv2.rotate(imagen, cv2.ROTATE_180) # Giro de 180 grados de la posicion actual
    elif tecla == ord('s'): # S  Tecla para salir
        print("Se presiono la tecla",tecla)
        break

#Muestra la imagen en una ventana
cv2.imshow('Imagen', imagen)
#Espero infinitamente la presion de una tecla
cv2.waitKey(0)

📚 Glosario de Funciones

OpenCV

OpenCV (Open Source Computer Vision Library) es una biblioteca de código abierto que se utiliza principalmente para procesamiento de imágenes y visión por computadora. En Python, se accede a través del módulo llamado cv2.

import

import es una palabra clave (keyword) que se usa para incluir módulos o bibliotecas externas en tu programa.

cv2.imread

Es una función de OpenCV (en el módulo cv2) que se usa para leer una imagen desde un archivo y cargarla en tu programa como una matriz (array de píxeles).

cv2.imshow

Es una función de OpenCV que sirve para mostrar una imagen en una ventana emergente.

while True

Es una estructura de bucle infinito en Python.

break

Es una palabra clave (keyword) en Python que se usa para salir de un bucle antes de que termine normalmente.
