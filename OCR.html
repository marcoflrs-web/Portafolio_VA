"""

#C:\Users\MATUTINO\AppData\Local\Programs\Tesseract-OCR

import cv2 #importa pythoncv para manipular
import pytesseract

pytesseract.pytesseract.tesseract_cmd = r"C:\Users\MATUTINO\AppData\Local\Programs\Tesseract-OCR\tesseract.exe"

#Cargar imagen
imgtexto = cv2.imread("frase2.jfif")

#Redimencionar el tamaño de la imagen
imgfinal = cv2.resize(imgtexto,(800,400))

#Convertir a escala de grises
imggris = cv2.cvtColor(imgfinal,cv2.COLOR_BGR2GRAY)

#Separamos el fondo con el texto
img_res = cv2.threshold(imggris,120,255,cv2.THRESH_BINARY)[1]
#Devuelve 2 valores, los pixeles y la imagen procesada

#Configurar OCR
texto = pytesseract.image_to_string(img_res,lang="spa")
#Como parametro le pasamos la variable con la imagen procesada y el idioma
#Imprimimos el titulo
print("Texto Destacado")
print(texto)

cv2.imshow("Imagen Analizada",imgfinal)
cv2.waitKey(0)
cv2.destroyAllWindows()

📚 Glosario de Funciones

pytesseract

Es una biblioteca de Python que actúa como interfaz (wrapper) para el motor de OCR (Reconocimiento Óptico de Caracteres) Tesseract, desarrollado originalmente por HP y mantenido por Google. En palabras simples, pytesseract permite extraer texto de imágenes.

cv2

Es el módulo principal de la biblioteca OpenCV en Python. (OpenCV = Open Source Computer Vision Library). En pocas palabras, cv2 se usa para procesar y analizar imágenes y videos, permitiendo que Python “vea” y entienda el contenido visual..

imread

Se usa para cambiar el tamaño de algo, por ejemplo: una imagen, una matriz (array) o incluso una ventana en una interfaz gráfica.

pytesseract.image_to_string()

Es una de las más usadas en la librería pytesseract, y sirve para extraer texto de una imagen usando OCR (Optical Character Recognition o Reconocimiento Óptico de Caracteres).

imshow

Mostrar la imagen en una ventana.

waitkey

Esperar hasta que el usuario presione una tecla.
