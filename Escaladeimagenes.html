📝 Código del Ejemplo

import cv2
#importa libreria opencv

    #Cargar imagen
gato = cv2.imread("gato.jpg")
while True:

    recorte = gato[100:423,250:600]
    #mostrar
    cv2.imshow("gato",gato)
    cv2.imshow("IMAGEN RECORTADA",recorte)

    tecla = cv2.waitKey(0)
    cv2.waitKey(0)
    cv2.destroyAllWindows()


    cv2.destroyAllWindows()

    if tecla == ord('o'):
        cv2.imshow('imagen original',gato)

    elif tecla == ord('y'):
        cv2.imshow('recorte',recorte)

    elif tecla == ord('x'):
        cv2.destroyAllWindows()
        break

📚 Glosario de Funciones

imread

Función que permite leer y abrir una imagen.

shape

Dimensiones de la imagen. El formato es: (alto, ancho, canales).

shape[0]

Representa el alto (número de filas) o la cantidad de píxeles verticales.

shape[1]

Representa el ancho (número de columnas) o la cantidad de píxeles horizontales.

shape[2]

Representa los canales de color.
